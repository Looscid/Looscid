Photosensitivity notice

This page's controls don't flash. The emulated PC screen can't be fully guaranteed, so Calm mode, on by default, hides it.

More details
  • What was checked: every animation, transition and script on this page, plus a frame-by-frame screen recording measured against the WCAG 2.3.1 limits (no more than three flashes in any second, including red flashes).
  • The page's own controls and text don't flash or move.
  • The emulated PC screen shows whatever the kernel draws, so it can't be fully guaranteed. While Calm mode is on, the screen is hidden; the console shows the same text.
  • Calm mode turns off all motion. It starts on, and your choice is remembered on this device.
  • Your device's Reduce Motion setting is always honoured: when it is on, nothing animates, even with Calm mode off.
  • Sound: the PC speaker only beeps when NexOS asks, after you press something. Turn it off with the Sound on checkbox. The emulator and its sound pause while this tab is in the background.
  • This was tested with automated measurement, not a clinical tool like PEAT, and not on every device.

If anything here ever flickers, please report it on GitHub.

About this page

This is not a simulation. It boots the same nexos-i686.iso you can build from the NexOS repository with make iso32: GRUB loads the 32-bit kernel, which sets up paging, interrupts and ring-3 apps. The PC is emulated by v86 (BSD-2-Clause), served from this site so it also works offline.

The kernel's shell runs on the serial port as well as the screen, which is how the console above reads and types. Prefer the lighter web twin? Open NexOS Web. This copy is part of Looscid; it came from the NexOS repository, copied from NexOS commit 0c2fb6b.
