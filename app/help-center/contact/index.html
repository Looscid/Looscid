Contact Us

Something broken, or an idea? Tell us. Looscid has no email; everything happens in the open.

Report a Dream, a person, a Circle or child safety

The Report Center in Looscid has every kind of report in one place, and My reports shows what happened to each one. Reports are private, only you and the Looscid mods see them.

Open the Report Center

Report a bug

Found something broken? This opens a new GitHub issue with your device already filled in, so you just say what happened. GitHub asks you to log in there.

Send feedback or join the Discord

Ideas, questions, or just want to say hi? Join the Looscid Discord. Anything you write in the #feedback channel turns into a GitHub issue by itself, and LooscidBOT answers you there with the link.

Join the Looscid Discord

Already using Looscid? Open Send Feedback (Profile, More, Feedback) writes a GitHub issue for you.
