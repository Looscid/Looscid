Tabs

the row of tabs at the top of a screen, like For You, Following and Federated.

what it is

Home has For You, Following and Federated. Discover, Circles, profiles and the Liked tab use the same row. one tab is picked, the list under it changes.

html

<div class="ftabs lc-feedtabs" role="tablist" aria-label="Feeds" id="feed-tablist"><button id="feed-tab-for-you" type="button" class="ftab on" role="tab" aria-selected="true" aria-setsize="3" aria-posinset="1" tabindex="0" aria-controls="feed-list">For You</button><button id="feed-tab-following" type="button" class="ftab" role="tab" aria-selected="false" aria-setsize="3" aria-posinset="2" tabindex="-1" aria-controls="feed-list">Following</button><button id="feed-tab-federated" type="button" class="ftab" role="tab" aria-selected="false" aria-setsize="3" aria-posinset="3" tabindex="-1" aria-controls="feed-list">Federated</button></div>

js

// arrow keys move between tabs (js/core.js, cut down)
tablist.addEventListener("keydown", function (e) {
  const tabs = Array.from(tablist.querySelectorAll("[role=tab]"));
  let i = tabs.indexOf(document.activeElement);
  if (e.key === "ArrowRight") i = (i + 1) % tabs.length;
  else if (e.key === "ArrowLeft") i = (i - 1 + tabs.length) % tabs.length;
  else return;
  e.preventDefault(); tabs[i].focus(); tabs[i].click();
});

it uses the classes from css/app.css and css/a11y.css, so it looks right anywhere in looscid.

how it works w voiceover

  • VoiceOver says "For You, selected, tab, 1 of 3". swipe right for the next tab.
  • double tap a tab to pick it. the list under it changes.
  • keyboard: Left and Right arrows move between tabs. braille display: Enter picks the tab ur on.
