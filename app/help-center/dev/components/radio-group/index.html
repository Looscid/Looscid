Radio group

pick exactly one: a fieldset with a legend and real radio buttons, like Text size.

what it is

when u can only pick one thing, it's a radio group. Text size in Settings, Accessibility, Vision is one, and so is Feed mode on Home and the reason list in the mod reason picker.

always a real fieldset with a legend, so the question gets said once when u enter the group.

states

live demos, drawn w looscid's real styles. look-only: nothing in them does anything.

normal

Default is picked.

another one picked

Larger is picked.

focused

focus ring on Large.

copy the code

html

<fieldset class="lc-fs" id="a11y-textSize"><legend class="lc-fs-l">Text size</legend><div class="lc-radios"><label class="lc-radio on"><input type="radio" name="lc-textsize" checked><span>Default</span></label><label class="lc-radio"><input type="radio" name="lc-textsize"><span>Large</span></label><label class="lc-radio"><input type="radio" name="lc-textsize"><span>Larger</span></label></div></fieldset>

it uses the classes from css/app.css and css/a11y.css, so it looks right anywhere in looscid.

how it works w voiceover

  • entering the group VoiceOver says "Text size", then "Default, radio button, checked, 1 of 3".
  • swipe right for the next choice, double tap to pick it.
  • keyboard: arrow keys move and pick in one go, the way radio buttons always work. braille display: Space or Enter picks the one ur on.
