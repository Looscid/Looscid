Pop-up menu

a button that opens a short menu, like Sort, a Dream's More menu and ReDream.

what it is

it's the button + little menu combo. Sort on Home uses it, so does a Dream's More menu, ReDream, and More on a profile.

the menu always ends with a Close item, so u never get stuck in it.

states

live demos, drawn w looscid's real styles. look-only: nothing in them does anything.

closed

just the button.

open

the menu is open and Latest is ticked.

focused item

focus on Latest inside the open menu.

copy the code

html

<div class="lmenu lmenu-inline"><button id="feed-sort-btn" type="button" class="btn bgb lc-btn" aria-haspopup="menu" aria-expanded="true" aria-controls="feed-sort"><span>Sort: Latest</span><span class="lmenu-caret" aria-hidden="true">▴</span></button><div class="lmenu-list"><ul id="feed-sort" role="menu" class="lmenu-ul" aria-label="Sort" tabindex="-1"><li role="menuitemradio" aria-checked="true" tabindex="0" class="lmenu-item act"><span class="lmenu-check" aria-hidden="true">✓</span><span>Latest</span></li><li role="menuitemradio" aria-checked="false" tabindex="-1" class="lmenu-item"><span class="lmenu-check" aria-hidden="true"></span><span>Popular</span></li><li role="menuitem" tabindex="-1" aria-label="Close Sort" class="lmenu-item lmenu-close"><span>Close</span></li></ul></div></div>

js

// how the menu moves focus (js/core.js LcMenu, cut down)
btn.addEventListener("click", function () { open(); list.querySelector("[tabindex='0']").focus(); });
list.addEventListener("keydown", function (e) {
  const items = Array.from(list.querySelectorAll("[role^='menuitem']"));
  const i = items.indexOf(document.activeElement);
  if (e.key === "ArrowDown") items[(i + 1) % items.length].focus();
  if (e.key === "ArrowUp") items[(i - 1 + items.length) % items.length].focus();
  if (e.key === "Enter" || e.key === " ") pick(items[i]);
  if (e.key === "Escape") { close(); btn.focus(); }
});

it uses the classes from css/app.css and css/a11y.css, so it looks right anywhere in looscid.

how it works w voiceover

  • the button says "Sort: Latest, pop up button". double tap opens it.
  • inside, each item is one swipe: "Latest, checked", "Popular", then "Close Sort".
  • picking an item closes the menu and puts focus back on the button, which now says the new choice.
  • two finger scrub or Escape closes it. braille display: Enter picks the item ur on.
