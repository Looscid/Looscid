Empty state

what a list says when there's nothing in it yet.

what it is

when a feed, a search or a list has nothing, we don't leave it blank. a short line says what's up and what u can do, like "No Dreams yet. Kinda peaceful, honestly."

states

live demos, drawn w looscid's real styles. look-only: nothing in them does anything.

empty feed

Home with no Dreams.

no Circles

the Circles list with nothing joined.

copy the code

html

<div class="es"><div class="esl">No Dreams yet. Kinda peaceful, honestly.</div><p style="font-size: 12px; color: var(--tx3); margin-top: 6px; line-height: 1.6;">When someone Dreams, it lands here. Or you could go first.</p></div>

it uses the classes from css/app.css and css/a11y.css, so it looks right anywhere in looscid.

how it works w voiceover

  • it's just text, so VoiceOver reads it as u swipe: "No Dreams yet. Kinda peaceful, honestly."
  • no fake buttons inside. if there's something to do, it points at the real button (like Create).
  • braille display: pan through it like any text.
