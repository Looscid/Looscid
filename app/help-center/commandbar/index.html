Use Commandbar

Commandbar lets you type what you want, like new dream or open settings, and Looscid does it.

Steps

  1. Press Open Commandbar (Profile, More). On a keyboard, press Control K or Command K from anywhere.
  2. Type a command and press Enter. For example: new dream, open settings or help.
  3. Type help for the top commands, or an area and help for one area, like cherry help.
  4. To see every command as a button, press Open Commands (Profile, More).
  5. Anything that isn't a command goes to Cherry, if Cherry is on.
