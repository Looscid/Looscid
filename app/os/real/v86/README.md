# v86 (bundled)

These files are the v86 x86 PC emulator by Fabian Hemmer and the v86
contributors, https://github.com/copy/v86, BSD-2-Clause (see LICENSE here):

- libv86.js and v86.wasm: from the v86 npm package, version 0.5.470
- seabios.bin and vgabios.bin: the BIOS images from the v86 repository
  (SeaBIOS and the VGA BIOS are LGPLv3; source at https://www.seabios.org/)

They are copied here unchanged so the page works offline, with no CDN.
