# DM Sans and DM Serif Display

Looscid's two fonts, served from this site instead of Google Fonts (Nov 9 2026), so no page loads anything from a CDN.

- `dm-fonts.css` has the `@font-face` rules. The app (`index.html`) and the Status page load it.
- The `.woff2` files are the Google Fonts web subsets (latin and latin-ext), unchanged: DM Sans v17 (variable, weights 400 to 700) and DM Serif Display v17.
- Credit: DM Sans by the DM Sans Project Authors (https://github.com/googlefonts/dm-fonts). DM Serif Display from the same DM fonts project, based on Source Serif by Adobe.
