Looscid / Policies

External links

Some links on Looscid lead to sites I don't run. I mark every one of them (external) right after the link text, so you know before you tap.

What the mark means

The link leaves Looscid. What you find there isn't mine, and I can't vouch for it.

How I treat them

External links open in a new tab, with rel set to noopener noreferrer, so the other page can't reach back into your Looscid tab or session. The visible label carries the (external) mark; the screen-reader name still states the exact destination, so it announces where the link really goes.

What stays unmarked

Links that stay on Looscid are never marked. Internal pages, and feeds I host myself like RSS, read normally.

What I don't control

Content, privacy, tracking, ads and security on an outside site belong to that site, not to me. I link out because it's useful, not because I endorse everything there.

If a link is broken or points somewhere it shouldn't

Report it through the Report Center. A report is private, only you and the Looscid mods see it.
