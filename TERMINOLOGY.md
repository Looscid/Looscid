# Looscid Official Terminology

This document defines the official language of Looscid. All contributors, collaborators and builders must use this terminology consistently across code, UI, ARIA labels, documentation and communications. No substitutions.

**The official terms:**

**Dream** — not Post. The words post, posted and posting never appear in the app. Only a license or legal text, or another project's own wording (for example a page describing another app), may use them. Hidden settings-search keywords may keep them, because they are never shown or spoken.

**ReDream** — not Repost

**Circle** — not Group or Community

**Dreamor** — not User or Member

**Why this matters:** Looscid is built on the belief that language shapes experience. Every word in this app was chosen deliberately.

## About this project (and official founding story)

Looscid was built by Alhasan Altameemi, a blind Dreamor, with Claude (Anthropic's AI) as his development partner. Accessibility is not a feature here, it is the foundation. This project exists to prove that the right tools and the right collaboration can build something meaningful regardless of what others assume about what's possible.
